Access

This site is built to be readable.

Pages use headings, landmarks, and a skip link. Text and buttons meet contrast expectations for ordinary reading. The calendar is a real table, and it still works if scripts are turned off. Filters and the mobile menu can be used with a keyboard. Past dates are marked in text as well as style.

The handbooks are PDFs. If a PDF is hard to read, email a director and ask for another format.

If something on this site blocks you, write bpineau@mckinneyisd.net or call (469) 302-6900, ext. 42717. Students without internet still receive paper notes, as described in the handbook.
